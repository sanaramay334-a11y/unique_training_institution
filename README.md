 Unique Training Institution ERP

A web-based Training Institution Enterprise Resource Planning (ERP) System developed to manage student, teacher, course, attendance, fees, results, and administrative records through a centralized platform.

 🚀 Features

* Admin login and dashboard
* Student management
* Teacher management
* Course management
* Student profiles
* Attendance management
* Attendance reports
* Fee management and fee receipts
* Results management
* Result printing
* Notices and announcements
* Student admission management
* Certificate verification
* Student login and dashboard
* Audit log management
* AI-assisted information/query functionality

 🛠️ Technologies Used

*PHP
* MySQL
* HTML5
* CSS3
* JavaScript
* Bootstrap
* XAMPP

 📊 Main Modules

### Student Management

Manage student records, profiles, admissions, and related information.

### Teacher Management

Add, update, view, and manage teacher records.

### Attendance

Record attendance and generate attendance-related reports.

### Fees

Manage fee records, pending fees, receipts, and fee reports.

### Results

Manage student results, generate result reports, and support result verification.

### Administration

Provides a centralized dashboard for managing institutional operations and records.

### AI Assistant

Includes an AI-assisted functionality for querying institutional information.

## 🗄️ Database

The application uses **MySQL** for storing and managing application data.

> **Security Note:** Database credentials, API keys, real student data, uploaded documents/photos, and database dumps are not included in this public repository.

## 💻 Local Development

To run this project locally:

1. Install **XAMPP**.
2. Start **Apache** and **MySQL**.
3. Place the project folder inside the XAMPP `htdocs` directory.
4. Create a MySQL database for the project.
5. Configure your local database connection in the appropriate configuration file.
6. Import the required database structure/data into your local MySQL database.
7. Open the project through the local XAMPP server.
